# Tisaraṇa-Pañcasīla ^0

Buddhaṃ saraṇaṃ gacchāmi. ^0-1

Dhammaṃ saraṇaṃ gacchāmi. ^0-2

Saṅghaṃ saraṇaṃ gacchāmi. ^0-3

Dutiyampi Buddhaṃ saraṇaṃ gacchāmi. ^0-4

Dutiyampi Dhammaṃ saraṇaṃ gacchāmi. ^0-5

Dutiyampi Saṅghaṃ saraṇaṃ gacchāmi. ^0-6

Tatiyampi Buddhaṃ saraṇaṃ gacchāmi. ^0-7

Tatiyampi Dhammaṃ saraṇaṃ gacchāmi. ^0-8

Tatiyampi Saṅghaṃ saraṇaṃ gacchāmi. ^0-9

**Pañcasīla** ^0-10

Pānātipātā veramaṇī sikkhāpadaṃ samādiyāmi. ^0-11

Adinnādānā veramaṇī sikkhāpadaṃ samādiyāmi. ^0-12

Kāmesu micchācārā veramaṇī sikkhāpadaṃ samādiyāmi. ^0-13

Musāvādā veramaṇī sikkhāpadaṃ samādiyāmi. ^0-14

Surāmeraya-majja-pamādaṭṭhānā veramaṇī sikkhāpadaṃ samādiyāmi. ^0-15

Āma Bhante. ^0-16

Sādhu! Sādhu! Sādhu! ^0-17
